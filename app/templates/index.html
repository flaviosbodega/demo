Buyer walkthrough

What this showroom proves

This browser demo mirrors the visible V49 desktop modules with a tiny sample archive. It uses approved sample objects and mock responses instead of production services.

  1. Start in Archive and inspect the three sample records.
  2. Run Search, Visual Search, Hallmarks, and Smart Search to see mocked research outputs.
  3. Use Sources to inspect configured pull sources, local object intake, and import history.
  4. Open Knowledge to see the private uploaded-reference-library concept.
  5. Use Commerce to validate a draft, then try Publish and confirm it is blocked.
  6. Use Review to see evidence diagnostics and non-mutating candidate actions.

What is protected

No production credentials, private research corpus, real database, live marketplace integration, or sensitive infrastructure is included.

Capability routing and tiers

RChive is not planned as one single local/remote switch. Capabilities can be local, hosted, or hybrid. Hosted AI, automation, concurrency, batch jobs, and some marketplace tools may be paid, metered, credit-based, or tier-limited.

Roadmap modules

Mobile Companion, Horology, and Numismatics are shown as Breadmaker beta modules being actively prepared and tested. Their demo pages disclose planned workflows without exposing unreleased internals.
